An algorithmic optimization engine that resolves complex course exam overlaps using graph vertex coloring heuristics.

Conflict-Free University Examination Scheduler

Timetable creation in academic institutions is a classic NP-complete constraint satisfaction challenge. This application models courses as vertices in an undirected graph, generates edges representing shared student enrollments, and applies heuristic graph coloring algorithms to determine the minimum number of conflict-free examination time slots.

● Live Cloud App
Conflict Graph Modeling: Vertices ($V$) represent subjects, edges ($E$) model mutual student enrollments.
Algorithmic Coloring: Employs greedy largest-first heuristics to compute the optimal chromatic number $\chi(G)$.
Visual Analytics: Generates real-time topological conflict graphs using NetworkX and Matplotlib.
Student Schedule Inspector: Allows individual students to query personalized clash-free timetables.
